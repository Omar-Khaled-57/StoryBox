# StoryBox3 visual identity

StoryBox3 presents personal photos as cinematic stories. The UI uses a near
black-blue canvas, electric blue actions, and violet/cyan gradients for the
AI-assisted storytelling identity.

| Role | Color |
| --- | --- |
| Background | ![#05080c](https://img.shields.io/badge/-%2305080c?style=flat-square&color=05080c) `#05080c` |
| Primary action | ![#0080ff](https://img.shields.io/badge/-%230080ff?style=flat-square&color=0080ff) `#0080ff` |
| Secondary / glow | ![#8c1aff](https://img.shields.io/badge/-%238c1aff?style=flat-square&color=8c1aff) `#8c1aff` |
| Story gradient | `#0080ff` → `#8c1aff` → `#00c8ff` → `#ff00cc` |

![StoryBox3 desktop and mobile preview](../dev/evice-mockup.png)

architecture, and setup details are in [`README.md`](../README.md).
